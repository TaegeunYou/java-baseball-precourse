# 💪 프로젝트 개요

숫자 야구 게임

# 게임 설명

- 기본적으로 1부터 9까지 서로 다른 수로 이루어진 3자리의 수를 맞추는 게임이다.
- 같은 수가 같은 자리에 있으면 스트라이크, 다른 자리에 있으면 볼, 같은 수가 전혀 없으면 포볼 또는 낫싱이란 힌트를
얻고, 그 힌트를 이용해서 먼저 상대방(컴퓨터)의 수를 맞추면 승리한다.
- [예] 상대방(컴퓨터)의 수가 425일 때, 123을 제시한 경우 : 1스트라이크, 456을 제시한 경우 : 1스트라이크 1볼,
789를 제시한 경우 : 낫싱
- 위 숫자 야구게임에서 상대방의 역할을 컴퓨터가 한다. 컴퓨터는 1에서 9까지 서로 다른 임의의 수 3개를 선택한다. 게
임 플레이어는 컴퓨터가 생각하고 있는 3개의 숫자를 입력하고, 컴퓨터는 입력한 숫자에 대한 결과를 출력한다.
- 이 같은 과정을 반복해 컴퓨터가 선택한 3개의 숫자를 모두 맞히면 게임이 종료된다.
- 게임을 종료한 후 게임을 다시 시작하거나 완전히 종료할 수 있다.
- 사용자가 잘못된 값을 입력할 경우 [ERROR]로 시작하는 에러 메시지를 출력하고 게임을 계속 진행할 수 있어야 한다.

# 📝 구현 기능 목록

### 게임 준비 기능
- [ ] 컴퓨터는 1에서 9까지 서로 다른 임의의 수 3개를 선택하고 저장한다.

### 사용자 입력 기능
- [x] `숫자를 입력해주세요 :`를 출력한다.
- [x] 사용자에게 입력을 받는다.
- [ ] 입력값을 검증한다.
  - [ ] 빈 문자열이나 공백이면 에러를 반환한다.
  - [ ] 입력이 숫자가 3개가 아니면 에러를 반환한다.
  - [ ] 숫자에 0이 포함되어 있으면 에러를 반환한다.
  - [ ] 숫자 3개가 아니면 에러를 반환한다.
  - [ ] 서로 다른 숫자가 아니면 에러를 반환한다.
  - [ ] 에러를 반환한 경우에는 에러 메시지를 출력한 후에 입력을 다시 받는다.

### 게임 기능
- [ ] 결과를 판단한다.
  - [ ] 스트라이크와 볼 갯수를 센다.
    - [ ] 같은 수가 같은 자리에 있으면 스트라이크를 추가한다.
    - [ ] 같은 수가 다른 자리에 있으면 볼을 추가한다.
  - [ ] 스트라이크와 볼이 없으면 낫싱으로 판단한다.
- [ ] 결과를 출력한다.
- [ ] 정답이 아니면 `숫자를 입력해주세요 :`를 출력하고 사용자에게 다시 입력을 받는다.

### 게임 종료 기능
- [ ] `3개의 숫자를 모두 맞히셨습니다! 게임 끝`를 출력하고 종료한다.
- [ ] `게임을 새로 시작하려면 1, 종료하려면 2를 입력하세요.`를 출력한다.
- [ ] 사용자에게 1 또는 2를 입력받는다.
- [ ] 다른 값인 경우에는 에러를 반환한다.
  - [ ] 에러를 반환한 경우에는 에러 메시지를 출력한 후에 입력을 다시 받는다.
- [ ] 1을 입력받은 경우 게임 준비 기능부터 게임을 새로 시작한다.
- [ ] 2를 입력받은 경우 게임을 종료한다.
